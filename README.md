
# To-Do List

Консольное приложение для управления списком дел.

## Возможности

- Добавление новых задач.
- Просмотр списка задач.
- Отметка выполненных задач.
- Удаление задач.
- Сохранение данных между запусками.

## Используемые технологии

- Python 3.10+
- Git
- GitHub

## Структура проекта

- main.py — точка входа в программу.
- ui.py — пользовательский интерфейс.
- logic.py — логика приложения.
- storage.py — работа с хранением данных.
- docs/ARCHITECTURE.md — описание архитектуры.
