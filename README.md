# To-Do List

Консольное приложение на Python для ведения списка задач. У каждой задачи есть
название, срок выполнения и статус. Данные сохраняются в JSON-файле между
запусками.

## Возможности

- Добавление задачи с названием и сроком выполнения.
- Просмотр всех задач и их статусов.
- Отметка задачи как выполненной.
- Удаление задачи.
- Автоматическая загрузка задач при запуске и сохранение изменений в `tasks.json`.
- Проверка пользовательского ввода и сообщения об ошибках загрузки или сохранения.

## Требования

- Python 3.10 или новее.
- Дополнительные пакеты не требуются: используются модули стандартной библиотеки Python.

## Запуск

Откройте терминал в папке проекта и выполните:

```bash
python main.py
```

При необходимости используйте команду `python3 main.py` или `py -3 main.py`,
в зависимости от настроек Python в вашей системе. При первом запуске задачи
будут пустыми; `tasks.json` создаётся рядом с `main.py` после первого изменения
списка.

## Структура проекта

- `main.py` — точка входа; загружает задачи и запускает меню.
- `ui.py` — меню, ввод пользователя и отображение задач.
- `logic.py` — модель задачи и операции со списком задач.
- `storage.py` — чтение и запись задач в `tasks.json`.
- `docs/ARCHITECTURE.md` — описание архитектуры и взаимодействия модулей.
