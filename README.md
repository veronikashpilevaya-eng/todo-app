# To-Do List

Консольное приложение на Python для ведения списка дел. Каждая задача содержит название, срок выполнения и статус. Данные сохраняются в JSON-файле между запусками.

## Возможности

- Добавление задачи с названием и сроком выполнения.
- Просмотр всех задач.
- Просмотр только невыполненных задач.
- Отметка задачи как выполненной.
- Удаление задачи по названию.
- Поиск задач по части названия без учёта регистра.
- Сохранение и загрузка задач в формате JSON.
- Сортировка задач по сроку выполнения.
- Автоматические тесты бизнес-логики и хранилища.

## Архитектура

- `main.py` — точка входа приложения.
- `logic.py` — классы `Task` и `TaskManager`, бизнес-логика и сериализация.
- `ui.py` — класс `ConsoleUI`, консольное меню и обработка ввода.
- `storage.py` — класс `Storage`, загрузка и сохранение JSON.
- `test_logic.py` — тесты классов `Task` и `TaskManager`.
- `test_storage.py` — тесты хранилища на временных файлах.
- `docs/` — архитектурная документация и UML-диаграммы.
- `.github/workflows/tests.yml` — автоматический запуск тестов в GitHub Actions.

## Требования

- Python 3.10 или новее.
- Дополнительные пакеты не требуются: используются модули стандартной библиотеки Python.

## Запуск приложения

Из корневого каталога проекта выполните:

```bash
python main.py
```

При необходимости используйте `python3 main.py` или `py -3 main.py`.

## Запуск тестов

```bash
python -m unittest -v
```

Тесты также запускаются автоматически при отправке изменений в рабочую ветку GitHub.
