
# Архитектура: Список дел (To-Do List)

## 1. Назначение проекта

Программа предназначена для создания и управления списком повседневных дел. Пользователь может добавлять задачи, просматривать их, отмечать выполненными и удалять.

## 2. Компоненты системы

### main.py
Точка входа в программу. Запускает приложение и передаёт управление пользовательскому интерфейсу.

### ui.py
Отвечает за взаимодействие с пользователем. Выводит меню, принимает команды и отображает информацию.

### logic.py
Содержит основную логику приложения. Отвечает за создание задач, изменение их статуса и удаление.

### storage.py
Отвечает за сохранение и загрузку списка дел из файла tasks.txt.

## 3. Связи между компонентами

- main.py запускает ui.py.
- ui.py обращается к logic.py.
- logic.py использует storage.py для работы с данными.

Зависимости между компонентами направлены сверху вниз.

## 4. Функциональные требования

1. Добавление дела с названием и сроком выполнения.
2. Просмотр всех дел с указанием статуса.
3. Возможность отметить дело выполненным.
4. Удаление выбранного дела.
5. Сохранение списка дел между запусками программы.

## 5. Принцип архитектуры

Каждый компонент отвечает за свою отдельную задачу. Слой хранения данных не должен зависеть от пользовательского интерфейса.
