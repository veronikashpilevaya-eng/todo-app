# Архитектура To-Do List

## Назначение приложения

Приложение позволяет вести список задач с названием, сроком выполнения и
статусом. Пользователь управляет задачами через консольное меню, а список
сохраняется в `tasks.json` рядом с файлами приложения.

## Модули

### `main.py`

Точка входа в приложение. При запуске загружает задачи через `storage.py`,
обрабатывает ошибки чтения или содержимого JSON и передаёт загруженный список
и функцию сохранения в пользовательский интерфейс.

### `ui.py`

Отвечает за взаимодействие с пользователем: показывает меню, считывает выбор,
название, срок и номер задачи, отображает список и сообщения. Проверяет ввод,
затем вызывает операции из `logic.py`. После изменения списка вызывает переданную
`main.py` функцию сохранения.

### `logic.py`

Содержит класс `Task` с полями названия, срока выполнения и статуса, а также
операции добавления задачи, отметки о выполнении и удаления по номеру. Этот
модуль не отвечает за пользовательский интерфейс или работу с файлами.

### `storage.py`

Загружает задачи из `tasks.json` и сохраняет их в JSON. При отсутствии файла
возвращает пустой список; некорректные данные сообщаются как ошибка, чтобы не
подменять их молча пустым списком.

## Взаимодействие модулей

```text
main.py ──загрузка/сохранение──> storage.py ──использует──> Task из logic.py
   │
   └──запускает──> ui.py ──операции над задачами──> logic.py
                        └──после изменений вызывает сохранение из storage.py
```

При старте `main.py` загружает задачи из JSON и передаёт их в `ui.py`.
Интерфейс использует `logic.py` для изменения списка. После добавления,
завершения или удаления задачи интерфейс вызывает функцию сохранения, переданную
точкой входа. `storage.py` преобразует объекты задач в JSON и обратно.

## Хранение данных

Задачи хранятся в файле `tasks.json` в каталоге приложения. Файл создаётся при
первом сохранении; существующие задачи автоматически загружаются при следующем
запуске.

## Запуск

Требуется Python 3.10 или новее. Из корневого каталога проекта запустите:

```bash
python main.py
```
