# Диаграмма классов и описание

## Task

Класс отдельного дела, реализован в модуле `logic.py`.

- `title: str` — название дела.
- `deadline: str` — срок выполнения.
- `done: bool` — статус выполнения.
- `mark_done(): None` — отмечает дело выполненным.
- `__str__(): str` — формирует текстовое представление дела.

При создании объекта проверяется, что название и срок не пустые, а статус имеет логический тип.

## TaskManager

Класс управления коллекцией дел, реализован в модуле `logic.py`.

- `tasks: list[Task]` — список объектов задач.
- `add_task(title: str, deadline: str): Task` — создаёт и добавляет задачу.
- `remove_task(title: str): None` — удаляет задачу по названию.
- `mark_done(title: str): None` — отмечает задачу выполненной.
- `get_all(): list[Task]` — возвращает копию списка задач.
- `get_pending(): list[Task]` — возвращает невыполненные задачи.
- `count(): int` — возвращает количество задач.
- `find_by_title(fragment: str): list[Task]` — ищет задачи по фрагменту названия без учёта регистра.

Если задача не найдена или входные данные некорректны, методы сообщают об ошибке через исключение `ValueError`.

## ConsoleUI

Класс консольного интерфейса, реализован в модуле `ui.py`.

- `manager: TaskManager` — объект управления задачами.
- `save_callback` — функция сохранения списка задач.
- `print_menu(): None` — выводит меню.
- `print_tasks(tasks): None` — отображает задачи.
- `add_flow(): None` — обрабатывает добавление задачи.
- `mark_done_flow(): None` — обрабатывает отметку о выполнении.
- `remove_flow(): None` — обрабатывает удаление.
- `run(): None` — запускает основной цикл меню.

Интерфейс перехватывает ошибки пользовательского ввода и сообщает о них пользователю.

## Хранение данных

Отдельный класс `TaskStorage` в текущей версии не создавался. Загрузка и сохранение реализованы функциями `load_tasks()` и `save_tasks()` в модуле `storage.py`. Данные хранятся в JSON-файле `tasks.json`.

## Связи между классами и модулями

1. `ConsoleUI` использует `TaskManager` для управления задачами.
2. `TaskManager` содержит список объектов `Task`.
3. `ConsoleUI` получает функцию сохранения через `save_callback`.
4. `main.py` связывает интерфейс, менеджер и функции хранения данных из `storage.py`.

## Совместимость

В `logic.py` сохранены прежние функции `add_task()`, `mark_task_done()` и `delete_task()` для совместимости с предыдущей версией проекта.
