# Диаграмма прецедентов и описание

## Актёр

**Пользователь** — человек, который взаимодействует с приложением через консольное меню.

## Прецеденты

### 1. Добавить дело
- **Цель:** добавить новое дело в список.
- **Основной сценарий:** пользователь выбирает добавление, вводит название и срок выполнения; программа создаёт дело.
- **Альтернативный сценарий:** если название или срок пустые, программа сообщает об ошибке и не добавляет дело.
- **Связь:** после добавления выполняется прецедент «Сохранить данные» (`include`).

### 2. Просмотреть список дел
- **Цель:** увидеть все дела, сроки и их текущие статусы.
- **Основной сценарий:** пользователь выбирает просмотр списка; программа выводит все дела.
- **Альтернативный сценарий:** если список пуст, программа сообщает об этом.

### 3. Отметить дело выполненным
- **Цель:** изменить статус выбранного дела на выполненный.
- **Основной сценарий:** пользователь выбирает дело по номеру; программа меняет его статус.
- **Альтернативный сценарий:** если номер некорректен или дело уже выполнено, программа выводит соответствующее сообщение.
- **Связи:** действие может выполняться при просмотре списка (`extend`); после изменения выполняется «Сохранить данные» (`include`).

### 4. Удалить дело
- **Цель:** удалить выбранное дело из списка.
- **Основной сценарий:** пользователь выбирает дело по номеру; программа удаляет его.
- **Альтернативный сценарий:** если номер не соответствует ни одному делу, программа сообщает об ошибке.
- **Связь:** после удаления выполняется «Сохранить данные» (`include`).

### 5. Сохранить данные
- **Цель:** сохранить актуальный список, чтобы он сохранился после завершения программы.
- **Основной сценарий:** программа записывает список дел в файл `tasks.json`.
- **Альтернативный сценарий:** если файл недоступен для записи, программа сообщает об ошибке сохранения.

## Итог

Основной актёр — Пользователь. Он взаимодействует с четырьмя пользовательскими прецедентами. Служебный прецедент «Сохранить данные» вызывается после добавления, изменения статуса и удаления дела.
